# Monte Carlo — 몬테카를로 시뮬레이션

## 1. 한 줄 요약

**Monte Carlo**는 불확실한 미래를 하나의 예측값으로 보지 않고, 수천~수만 개의 가능한 시나리오를 만들어 확률적으로 분석하는 방법입니다.

트레이딩에서는 다음 질문에 답할 때 씁니다.

- 이 전략이 망할 확률은 얼마인가?
- 최대 손실이 어느 정도까지 커질 수 있는가?
- 연속 손실이 몇 번까지 나올 수 있는가?
- 포지션 사이즈를 키우면 파산 확률이 얼마나 증가하는가?
- 현재 백테스트 결과가 우연일 가능성은 얼마나 되는가?

## 2. 핵심 아이디어

백테스트 결과가 다음과 같다고 합시다.

```text
총 거래 수: 300회
승률: 42%
평균 이익: +2.1%
평균 손실: -1.2%
```

이 숫자만 보면 괜찮아 보일 수 있습니다. 하지만 실제로 중요한 것은 거래 순서입니다.

동일한 300개의 거래 결과라도:

- 초반에 손실이 몰리면 계좌가 크게 망가짐
- 수익과 손실이 고르게 섞이면 버틸 수 있음
- 극단 손실이 몇 번 섞이면 전략이 무너질 수 있음

Monte Carlo는 거래 결과를 무작위로 섞거나, 수익률 분포에서 다시 샘플링해서 수많은 미래 경로를 만듭니다.

## 3. 트레이딩에서의 대표 사용법

### 3.1 Trade Resampling

백테스트에서 나온 개별 거래 PnL을 무작위로 다시 뽑아 여러 계좌 곡선을 만듭니다.

예:

```text
원래 거래 결과:
[+1.2%, -0.8%, +2.1%, -1.0%, ...]

시뮬레이션 1:
[-1.0%, -0.8%, +1.2%, +2.1%, ...]

시뮬레이션 2:
[+2.1%, -1.0%, -1.0%, +1.2%, ...]
```

이를 수천 번 반복해서 최악의 경우와 일반적인 경우를 봅니다.

### 3.2 Return Path Simulation

최근 가격 수익률의 평균과 변동성을 이용해 미래 가격 경로를 생성합니다.

```text
S_{t+1} = S_t * exp((μ - 0.5σ²)dt + σ sqrt(dt) Z)
```

여기서 `Z`는 표준정규분포 난수입니다.

이를 통해 다음을 볼 수 있습니다.

- 익절선에 먼저 닿을 확률
- 손절선에 먼저 닿을 확률
- N봉 후 기대 가격 분포
- liquidation 확률

### 3.3 Position Sizing Simulation

동일 전략이라도 포지션 크기에 따라 생존 가능성이 달라집니다.

Monte Carlo로 다음을 비교할 수 있습니다.

```text
1회 거래당 5% 사용
1회 거래당 10% 사용
1회 거래당 25% 사용
1회 거래당 100% 사용
```

결과적으로 “수익률이 가장 높은 사이즈”가 아니라 “파산 확률을 감당할 수 있는 사이즈”를 찾는 데 사용합니다.

## 4. 봇에 넣으면 좋은 지표

### 4.1 Risk of Ruin

계좌가 특정 손실 한도 이하로 떨어질 확률입니다.

예:

```text
초기자금 10,000 USDT
파산 기준 5,000 USDT
Monte Carlo 10,000회 실행
그중 1,200회가 5,000 아래로 하락
Risk of Ruin = 12%
```

### 4.2 Expected Max Drawdown

수천 개 경로에서 최대 낙폭의 평균과 분위수를 봅니다.

예:

```text
평균 MDD: 18%
95% MDD: 42%
99% MDD: 61%
```

이 경우 “운 나쁘면 60% 이상 빠질 수 있다”는 뜻입니다.

### 4.3 Probability of Profit

특정 기간 후 수익으로 끝날 확률입니다.

```text
1개월 후 플러스 확률: 57%
3개월 후 플러스 확률: 63%
6개월 후 플러스 확률: 71%
```

### 4.4 Consecutive Loss Distribution

연속 손실이 몇 번까지 나올 수 있는지 봅니다.

```text
평균 최대 연속 손실: 6회
95% 최대 연속 손실: 13회
99% 최대 연속 손실: 18회
```

이 정보는 전략 중단 조건과 포지션 사이즈 결정에 중요합니다.

## 5. 현재 5분봉 7일선 전략에 적용하는 방법

현재 전략은 다음 구조입니다.

```text
5분봉 7일선 돌파
다음 봉 확인
볼린저밴드 필터
볼린저밴드 익절
7일선 이탈/손절 청산
```

여기에 Monte Carlo를 붙이면 다음을 할 수 있습니다.

1. 백테스트에서 모든 거래 PnL을 저장
2. 거래 결과를 무작위 재배열
3. 10,000개의 계좌 곡선 생성
4. 다음 값 계산
   - 파산 확률
   - 95% 최악 MDD
   - 예상 최종 잔고
   - 손실 연속 구간
5. 포지션 사이즈별로 반복

## 6. 간단한 의사코드

```python
trades = [-0.01, 0.02, -0.005, 0.015, ...]
initial_balance = 10000
simulations = []

for _ in range(10000):
    balance = initial_balance
    path = [balance]
    sampled_trades = random.choices(trades, k=len(trades))

    for r in sampled_trades:
        balance *= (1 + r)
        path.append(balance)

    simulations.append(path)

# 이후 최종 잔고 분포, MDD 분포, 파산 확률 계산
```

## 7. 장점

- 단일 백테스트보다 훨씬 현실적인 위험 추정 가능
- 전략의 최악 상황을 미리 볼 수 있음
- 포지션 사이징에 직접 도움
- 과최적화 전략을 걸러낼 수 있음
- “평균 수익”보다 “생존 가능성”을 판단할 수 있음

## 8. 한계

- 과거 거래 분포가 미래에도 유지된다는 가정이 필요함
- 시장 regime 변화는 단순 resampling으로 반영하기 어려움
- 극단적인 블랙스완은 과거 데이터에 없으면 반영되지 않음
- 입력 데이터가 나쁘면 시뮬레이션도 의미가 없음

## 9. 이 프로젝트에서 구현 우선순위

Monte Carlo는 매우 유용하므로 우선순위가 높습니다.

추천 구현 순서:

1. 백테스트 결과에서 거래별 수익률 저장
2. Monte Carlo resampling 함수 추가
3. 결과 API 추가
4. dashboard에 분포 차트 추가
5. risk of ruin 기반 position sizing 추가

## 10. 실제 의사결정 예시

백테스트 수익률이 +20%인 전략 A와 +8%인 전략 B가 있다고 합시다.

Monte Carlo 결과:

```text
전략 A:
평균 수익률 +20%
95% MDD 72%
파산 확률 18%

전략 B:
평균 수익률 +8%
95% MDD 19%
파산 확률 0.5%
```

실전에서는 전략 B가 더 좋은 선택일 수 있습니다.

## 11. 요약

Monte Carlo는 “수익이 날까?”보다 “망하지 않고 버틸 수 있을까?”를 확인하는 도구입니다.

자동매매에서는 수익률보다 생존이 먼저이므로, 이 프로젝트에 꼭 넣을 가치가 있습니다.
