# Market Microstructure — 시장미시구조

## 1. 한 줄 요약

**Market Microstructure(시장미시구조)**는 가격이 차트 위에서 어떻게 움직이는지가 아니라, 실제 시장 내부에서 주문이 어떻게 제출되고 체결되며 가격이 형성되는지를 연구하는 분야입니다.

핵심 대상:

- 호가창
- bid/ask spread
- market order
- limit order
- 체결량
- 유동성
- 슬리피지
- order flow
- queue position
- 거래소 매칭 엔진

## 2. 왜 중요한가

백테스트에서는 보통 이렇게 가정합니다.

```text
신호 발생 → 다음 봉 시가에 원하는 수량 전부 체결
```

하지만 실전에서는 그렇지 않습니다.

실전에서는:

- 호가가 얇으면 원하는 가격에 체결되지 않음
- 시장가 주문은 스프레드를 먹고 들어감
- 주문 수량이 크면 가격을 밀어버림
- 거래소 지연 때문에 늦게 체결됨
- 캔들 가격은 실제 체결 가능 가격이 아닐 수 있음

즉 전략이 백테스트에서 좋아도 시장미시구조를 무시하면 실전에서 망가질 수 있습니다.

## 3. 핵심 개념

### 3.1 Bid와 Ask

- Bid: 매수자가 제시한 가격
- Ask: 매도자가 제시한 가격

시장가 매수는 Ask를 때리고, 시장가 매도는 Bid를 때립니다.

### 3.2 Spread

Ask와 Bid의 차이입니다.

```text
spread = ask - bid
```

스프레드가 넓을수록 진입 즉시 손해가 커집니다.

### 3.3 Order Book

호가창입니다.

예:

```text
Ask 100.3 | 2 BTC
Ask 100.2 | 1 BTC
Ask 100.1 | 3 BTC
----------------
Bid 100.0 | 4 BTC
Bid  99.9 | 2 BTC
Bid  99.8 | 5 BTC
```

시장가로 많이 사면 위쪽 ask 물량을 순서대로 먹으면서 평균 체결가가 나빠집니다.

### 3.4 Slippage

기대한 가격과 실제 체결 가격의 차이입니다.

```text
expected price = 100.0
actual fill price = 100.2
slippage = 0.2%
```

### 3.5 Market Impact

내 주문 자체가 시장 가격을 움직이는 효과입니다.

작은 계좌는 영향이 작지만, 유동성이 낮은 코인이나 큰 주문에서는 중요합니다.

### 3.6 Order Flow

시장에 들어오는 매수/매도 주문의 흐름입니다.

order flow가 한쪽으로 강하면 단기 가격 방향에 영향을 줍니다.

## 4. 트레이딩에서 쓰는 곳

### 4.1 슬리피지 예측

전략 수익률이 거래당 0.2%인데 실제 슬리피지가 0.15%라면 수익이 거의 사라집니다.

시장미시구조를 보면 진입 전 다음을 확인할 수 있습니다.

- 현재 spread
- 상위 N호가 유동성
- 주문 수량 대비 호가 물량
- 최근 체결 강도

### 4.2 주문 방식 선택

시장가 주문과 지정가 주문은 장단점이 다릅니다.

시장가:

- 장점: 즉시 체결
- 단점: 스프레드와 슬리피지 비용

지정가:

- 장점: 더 좋은 가격 가능
- 단점: 미체결 위험

### 4.3 진입 필터

좋은 차트 신호가 나와도 호가가 나쁘면 진입하지 않을 수 있습니다.

예:

```text
spread_pct > 0.05% 이면 진입 금지
상위 5호가 유동성이 주문 크기의 3배 미만이면 진입 금지
최근 체결이 반대 방향으로 강하면 진입 보류
```

### 4.4 HFT와 단타

짧은 시간 단위 전략에서는 차트보다 호가창이 더 중요할 수 있습니다.

5분봉 전략은 HFT는 아니지만, 실전 체결 품질을 개선하려면 microstructure를 일부 반영해야 합니다.

## 5. 현재 봇에 부족한 점

현재 봇은 백테스트에서 기본 슬리피지와 liquidity impact 정도를 반영합니다.

하지만 아직 부족한 것:

- 실시간 bid/ask spread 체크
- order book depth 체크
- 시장가/지정가 선택 로직
- partial fill 처리
- 주문 대기열 위치 추정
- 체결 강도 분석
- 거래소 지연 측정

## 6. 이 프로젝트에 적용하는 현실적인 방법

### 6.1 진입 전 spread 필터

```text
if spread_pct > max_spread_pct:
    진입 금지
```

### 6.2 호가 깊이 필터

```text
if top_5_ask_liquidity < order_notional * 3:
    롱 진입 금지
```

### 6.3 시장가 대신 분할 주문

큰 주문을 한 번에 넣지 않고 여러 조각으로 나눕니다.

현재 프로젝트에도 order split 관련 설정이 있으므로 더 발전시킬 수 있습니다.

### 6.4 체결 비용을 백테스트에 반영

단순 고정 슬리피지가 아니라 다음 기반으로 비용을 추정합니다.

```text
slippage = spread/2 + impact_factor * order_size / visible_liquidity
```

## 7. 데이터 요구사항

시장미시구조를 제대로 다루려면 다음 데이터가 필요합니다.

- order book snapshot
- trade tick data
- bid/ask quotes
- spread history
- depth history
- order fill history
- latency measurement

캔들 데이터만으로는 한계가 큽니다.

## 8. 5분봉 전략과 연결

현재 5분봉 7일선 돌파 전략은 수익폭이 크지 않습니다. 이런 전략에서는 체결 비용이 매우 중요합니다.

예를 들어:

```text
평균 거래 기대수익: 0.25%
왕복 수수료: 0.10%
슬리피지: 0.15%
실제 기대수익: 0.00%
```

따라서 microstructure 필터를 추가하면 손실 거래를 줄일 수 있습니다.

## 9. 장점

- 백테스트와 실전의 괴리를 줄임
- 나쁜 체결을 피할 수 있음
- 단기 전략의 실제 성과 개선 가능
- 주문 방식 개선 가능

## 10. 한계

- 데이터 저장량이 큼
- 구현 난이도가 높음
- 거래소 API 제한에 걸릴 수 있음
- 너무 복잡하게 만들면 유지보수가 어려움

## 11. 이 프로젝트에서 우선순위

우선순위는 높습니다.

추천 순서:

1. 현재 spread 조회 API 추가
2. 진입 전 max_spread_pct 필터 추가
3. order book top depth 조회
4. 주문 크기 대비 depth 필터 추가
5. 백테스트에 동적 슬리피지 모델 추가
6. 실전 fill price와 expected price 비교 저장

## 12. 요약

시장미시구조는 “신호가 맞았는가?”보다 “그 신호를 실제로 좋은 가격에 체결할 수 있었는가?”를 다룹니다.

자동매매 실전 성과를 높이려면 반드시 필요한 분야입니다.
