# Stochastic Calculus — 확률미적분

## 1. 한 줄 요약

**Stochastic Calculus(확률미적분)**는 가격, 금리, 변동성처럼 시간이 지나며 무작위로 움직이는 값을 수학적으로 다루는 도구입니다. 일반 미적분이 부드러운 곡선을 다룬다면, 확률미적분은 흔들림이 심하고 예측 불가능한 경로를 다룹니다.

트레이딩에서는 주로 다음에 쓰입니다.

- 옵션 가격 모델링
- 변동성 모델링
- 리스크 측정
- 포트폴리오 동적 헤징
- 확률적 가격 경로 생성
- 파생상품 평가

## 2. 왜 일반 미적분으로 부족한가

일반적인 미적분은 함수가 비교적 매끄럽다고 가정합니다.

예를 들어:

```text
가격 = f(t)
```

라면 시간 `t`가 조금 변할 때 가격도 부드럽게 변한다고 생각합니다. 하지만 실제 시장 가격은 그렇지 않습니다.

- 갑자기 튀는 갭이 있음
- 뉴스에 급등락함
- 작은 시간 단위에서도 노이즈가 큼
- 수익률 분포가 정규분포보다 꼬리가 두꺼움
- 변동성이 시간에 따라 변함

그래서 금융 가격은 보통 다음처럼 봅니다.

```text
가격 = 결정론적 추세 + 무작위 충격
```

확률미적분은 이 무작위 충격을 포함해 가격 과정을 다루는 수학입니다.

## 3. 핵심 개념

### 3.1 확률과정

확률과정은 시간에 따라 변하는 확률 변수입니다.

예:

```text
S_t = t 시점의 BTC 가격
```

`S_t`는 고정된 숫자가 아니라 미래에는 여러 값이 될 수 있는 확률 변수입니다.

### 3.2 Brownian Motion / Wiener Process

브라운 운동은 금융 모델에서 가장 자주 쓰이는 무작위 움직임입니다.

특징:

- 연속적인 경로
- 독립적인 증가분
- 평균 0
- 분산은 시간에 비례

간단히 말하면 “계속 흔들리는 랜덤 경로”입니다.

기호로는 보통 `W_t`라고 씁니다.

### 3.3 Stochastic Differential Equation, SDE

가격 움직임을 다음처럼 씁니다.

```text
dS_t = μ S_t dt + σ S_t dW_t
```

의미:

- `S_t`: 현재 가격
- `μ`: 기대 수익률 또는 drift
- `σ`: 변동성
- `dt`: 아주 작은 시간 변화
- `dW_t`: 무작위 충격

해석하면:

```text
가격 변화 = 추세 성분 + 랜덤 변동성 성분
```

### 3.4 Ito's Lemma

Ito's Lemma는 확률미적분에서 가장 중요한 공식 중 하나입니다.

일반 미적분의 chain rule과 비슷하지만, 무작위 항 때문에 추가 보정항이 생깁니다.

금융에서는 옵션 가격 공식, 리스크 민감도, 헤징 공식 유도에 사용됩니다.

## 4. 트레이딩에서의 사용처

### 4.1 옵션 가격

Black-Scholes 모델은 확률미적분의 대표적인 결과입니다.

전제:

```text
주가가 geometric Brownian motion을 따른다
```

이 가정에서 콜옵션과 풋옵션의 이론 가격을 계산할 수 있습니다.

### 4.2 동적 헤징

옵션을 팔았을 때 가격 변동에 따른 위험을 줄이기 위해 기초자산을 계속 사고팝니다.

이를 delta hedging이라고 합니다.

확률미적분은 “얼마나 사거나 팔아야 위험이 중립이 되는지”를 계산하는 데 필요합니다.

### 4.3 변동성 모델링

단순한 Black-Scholes는 변동성을 고정값으로 둡니다. 하지만 실제 시장에서 변동성은 변합니다.

그래서 다음 같은 모델이 나옵니다.

- Heston model
- SABR model
- Local volatility model
- Stochastic volatility model

이런 모델들은 대부분 확률미적분 위에 세워져 있습니다.

### 4.4 리스크 모델

포트폴리오 가치가 미래에 어떤 분포를 가질지 계산하려면 가격 경로 모델이 필요합니다.

확률미적분은 다음의 기반이 됩니다.

- Value at Risk, VaR
- Expected Shortfall
- Stress testing
- tail risk modeling

## 5. 우리 봇에 바로 필요한가

현재 이 OKX 트레이딩 봇은 이동평균, 볼린저밴드, ATR 기반의 룰 전략입니다. 이런 수준에서는 확률미적분을 직접 구현할 필요는 크지 않습니다.

하지만 다음 단계에서는 간접적으로 유용합니다.

- 변동성 기반 포지션 사이징
- Monte Carlo 리스크 시뮬레이션
- 가격 경로 생성
- 옵션/변동성 전략 확장
- liquidation probability 추정

## 6. 지금 전략에 적용한다면

예를 들어 5분봉 7일선 돌파 전략에 확률미적분을 직접 넣기보다는 다음처럼 단순화해 적용할 수 있습니다.

```text
최근 수익률의 평균과 변동성을 추정한다.
가격이 geometric Brownian motion 비슷하게 움직인다고 가정한다.
다음 N개 봉 동안 손절선에 먼저 닿을 확률과 익절선에 먼저 닿을 확률을 계산한다.
익절 확률 * 기대이익 > 손절 확률 * 기대손실일 때만 진입한다.
```

즉 확률미적분은 “진입 신호가 나왔을 때, 이 트레이드의 확률적 기대값이 플러스인가?”를 계산하는 방향으로 쓰는 것이 현실적입니다.

- 리스크를 수학적으로 표현할 수 있음

- 모델 가정이 현실과 다를 수 있음
