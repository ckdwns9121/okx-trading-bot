# ICT Liquidity FVG 개선 검증 리포트

- 작성일: 2026-04-26
- 대상 전략: `ict_liquidity_fvg`
- 변경 범위: 기존 ICT sweep → MSS → FVG retest 구조는 유지하고, 진입 직전 신호 품질 필터를 추가했다.

## 추가한 개선점

1. **UTC 세션 필터**: 런던/뉴욕 유동성 시간대처럼 지정한 UTC 시간 안에서만 진입 가능.
2. **EMA 추세 필터**: long은 종가가 EMA 위, short는 종가가 EMA 아래일 때만 진입 가능.
3. **ATR 변동성 필터**: 변동성이 너무 낮거나 과열된 구간을 제외 가능.
4. **MSS 품질 필터**: MSS 캔들의 body 비율과 돌파 폭을 최소 기준으로 제한 가능.
5. **Retest 확인 필터**: long retest는 양봉, short retest는 음봉일 때만 진입하도록 제한 가능.

## 검증 조건

- 기간: `2026-03-01` ~ `2026-04-25`
- 종목: `BTC-USDT-SWAP`, `ETH-USDT-SWAP`, `SOL-USDT-SWAP`
- 시간봉: `15m`
- 초기 자본: `10,000 USDT`
- 비용: 수수료 `0.05%`, 슬리피지 `0.05%`, 펀딩 `0.01%/8h`, 유동성 영향 `0.1`

## 종목별 관찰

- **BTC 15m**: 세션 필터를 넣으면 손실이 크게 줄었고, 일부 RR 조합은 소폭 양수였다.
- **ETH 15m**: 개선 후에도 대부분 음수다. 현재 ICT 모델과 가장 맞지 않는다.
- **SOL 15m**: 일부 조합에서 양수였지만 거래 수가 적어 통계적으로 약하다.

## 결론

이번 개선으로 **손실 폭과 노이즈는 줄었지만 수익성 검증은 아직 통과하지 못했다.**
즉, 전략은 이전보다 더 안전하게 필터링되지만 아직 “돈 되는 전략”으로 볼 수 없다.
